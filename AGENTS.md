# Titulo do documento

## 1. Contexto

Preciso desenvolver um website com o tema de Pokémon para um trabalho individual da faculdade, que fale sobre meus gostos pessoais e como o tema se relaciona com a minha vida.

## 2. Objetivo

A maior finalidade desse projeto é fazer com que o usuário interaja com o site de alguma forma, gerando dados e relatórios que serão apresentados dentro de uma dashboard.

## 3. Escopo

- **Dentro do escopo:** Homepage, tela de cadastro e login, tela de conexão do tema com a minha vida, tela interativa e dashboard.

## 4. Funcionalidades

Dentro do sistema, será possível visualizar a tema inicial com informações sobre o mundo Pokémon e algumas explicações sobre o mesmo, seguindo para a tela de conexão, eu falarei como a franquia foi importante para a minha vida e como ela acompanhou a minha evolução durante os anos. A tela de cadastro será responsável por cadastrar os usuários no sistema e fazer validações nos campos para verificar se tudo está de acordo com o padrão, a tela de login se certificará de que as informações informadas são corretas e redirecionará o usuário a tela interativa e tela de dashborad. A tela interativa terá um sistema de advinhação dos Pokémon a partir de sua silhueta
